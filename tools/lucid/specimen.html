Design system · v0.1 proposal

Lucid

A calm, precise language for agentic enterprise work. Neutral surfaces keep people focused on decisions. One signature, the agent gradient, appears only where the agent has authored something, so it is always clear who did what.

01

Quiet by default

Neutral canvas, hairlines, soft depth. Colour is spent only on meaning.

02

Show who did it

Agent work carries the gradient line and spark. People’s actions stay ink.

03

Evidence over scores

Every recommendation shows the change, the reason and its source.

04

Dense, never cramped

Tabular figures, 44px rows, generous rhythm between groups.

# AI-native framework templates

Source for the branded framework templates (template + NorthStar worked example).

- `gen.js` + `style.css` → builds the HTML page. Run `node gen.js`, then wrap the output in a document head as in `public/templates/ai-native-frameworks.html`.
- `*.js` (agent-mission-blueprint, intelligence-opportunity-canvas, experience-blueprint-kit, prototype-review-kit) → Figma Plugin API scripts used through the Figma MCP `use_figma` tool. The first two have been run; the last two are ready to run once Figma MCP calls are available again.

Published (staging): `/templates/ai-native-frameworks.html` (noindex, not linked from the site yet).
NorthStar GmbH is a fictional company; all example figures are illustrative.
